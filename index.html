Basil Farm

A small ESP32 plant-monitoring project
Happy birthday, Moray! This is the best birthday gift ever since you love your basil farm and you can write some code to monitor it yourself.

What you're building

One Beetle ESP32-C3 reads three soil-moisture sensors, a BME280 for temperature/humidity, and three BH1750 light sensors. It then puts the readings on a simple webpage over Wi-Fi.

There are no pumps and no cloud account. The readings go from the sensors to the ESP32 and then to a webpage you open in a browser.

1. Get the ESP32 talking

  1. Install Arduino IDE and add the ESP32 board package.
  2. Select the ESP32-C3 board that matches your Beetle, connect it by USB, and select its serial port.
  3. Upload this first:
void setup() {
  Serial.begin(115200);
}

void loop() {
  Serial.println("Basil Farm online");
  delay(1000);
}

Open Serial Monitor at 115200. You should see the message once a second.

2. Wire the BME280

The BME280 uses I²C.

BME280ESP32-C3
VIN / 3V33V3
GNDGND
SDASDA pin on your Beetle
SCLSCL pin on your Beetle

The exact GPIO numbers depend on the Beetle C3 revision. Check the pin labels printed on the board rather than copying GPIO numbers from a different ESP32.

Test code

#include <Wire.h>
#include <Adafruit_BME280.h>

Adafruit_BME280 bme;

void setup() {
  Serial.begin(115200);
  Wire.begin();

  if (!bme.begin(0x76)) {
    Serial.println("BME280 not found");
    while (1) delay(10);
  }
}

void loop() {
  Serial.print("Temp: ");
  Serial.print(bme.readTemperature());
  Serial.print(" C  Humidity: ");
  Serial.print(bme.readHumidity());
  Serial.println(" %");
  delay(2000);
}

If 0x76 fails, try 0x77.

3. Add the three soil sensors

Each capacitive sensor normally has VCC, GND and AOUT.

SensorESP32
VCC3V3
GNDGND
AOUTThree separate ADC-capable GPIOs

Use ADC-capable pins on the ESP32-C3, not GPIO numbers from a classic ESP32.

const int MOISTURE_1 = /* ADC pin */;
const int MOISTURE_2 = /* ADC pin */;
const int MOISTURE_3 = /* ADC pin */;

void setup() {
  Serial.begin(115200);
}

void loop() {
  Serial.println(analogRead(MOISTURE_1));
  Serial.println(analogRead(MOISTURE_2));
  Serial.println(analogRead(MOISTURE_3));
  delay(1000);
}

Calibration

Don't treat the raw number as a universal percentage. For each sensor:

  1. Record the reading in dry-ish soil.
  2. Record it again in well-watered soil.
  3. Map that range to 0–100% in software.

Keep each sensor with the same plant/pot after calibration.

4. Add the BH1750 light sensors

BH1750s also use I²C. SDA and SCL are shared, so all three sensors can be on the same bus only if they have different I²C addresses.

Important: BH1750 modules have only two possible addresses, 0x23 and 0x5C, set by the ADDR pin. Three identical modules can't share one bus as they are. Options:
  • Two sensors, no extra parts: leave ADDR unconnected on one (0x23) and wire ADDR to 3V3 on the other (0x5C).
  • All three: add a TCA9548A multiplexer and put each BH1750 on its own channel.
  • Mixed sensors: use two BH1750s and a different lux sensor with its own address for the third, such as a VEML7700 (0x10).

For the first build, get one BH1750 working, then choose an option above.

Soldering the header pins

The BH1750 board comes with a strip of header pins that isn't attached. You need a soldering iron, solder, and your breadboard to hold things in place.

  1. Break the header strip to match the number of holes on the board. Fit all of them, including ADDR, in case you want to change the address later.
  2. Push the strip into the breadboard with the long pins down.
  3. Rest the BH1750 on top of the short pins, with the component side up, so the pins come through the holes.
  4. Heat the iron to about 330 °C. Touch it to the pin and the pad together for a second or two, then feed in a little solder.
  5. Remove the solder first, then the iron. Solder one end pin and check the board is sitting flat. Reheat that joint to adjust if not, then solder the rest.
  6. Let the joints cool without moving the board.

A good joint is shiny and shaped like a small cone. Dull or blobby joints should be reheated. Check that no solder connects two neighbouring pins. Keep each joint to a few seconds so the small sensor doesn't overheat.

#include <BH1750.h>

BH1750 lightMeter;

void setup() {
  Serial.begin(115200);
  Wire.begin();

  if (!lightMeter.begin()) {
    Serial.println("BH1750 not found");
    while (1) delay(10);
  }
}

void loop() {
  Serial.print("Light: ");
  Serial.print(lightMeter.readLightLevel());
  Serial.println(" lux");
  delay(1000);
}

For a second sensor with ADDR wired to 3V3, pass its address to begin():

BH1750 lightMeter2;

lightMeter2.begin(BH1750::CONTINUOUS_HIGH_RES_MODE, 0x5C);

5. Put it together

┌───────────────┐ soil 1 ──────►│ │ soil 2 ──────►│ │ soil 3 ──────►│ ESP32-C3 │──── Wi-Fi ────► phone/laptop BME280 ──────►│ │ BH1750(s) ───►│ │ └───────────────┘

The web dashboard works like this:

  1. ESP32 connects to Wi-Fi.
  2. /api/status returns JSON with the latest readings.
  3. / serves the dashboard.
  4. JavaScript on the dashboard calls /api/status every few seconds.

Minimal web server

#include <WiFi.h>
#include <WebServer.h>

const char* ssid = "YOUR_WIFI";
const char* password = "YOUR_PASSWORD";

WebServer server(80);

void handleStatus() {
  String json = "{";
  json += "\"moisture1\":" + String(analogRead(MOISTURE_1)) + ",";
  json += "\"moisture2\":" + String(analogRead(MOISTURE_2)) + ",";
  json += "\"moisture3\":" + String(analogRead(MOISTURE_3));
  json += "}";
  server.send(200, "application/json", json);
}

void setup() {
  Serial.begin(115200);
  WiFi.begin(ssid, password);

  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
  }

  Serial.print("Open: http://");
  Serial.println(WiFi.localIP());

  server.on("/api/status", handleStatus);
  server.begin();
}

void loop() {
  server.handleClient();
}

After uploading, the Serial Monitor will print an address such as 192.168.1.42. Open that address on a device connected to the same Wi-Fi.

6. Make the dashboard

The page fetches the JSON and displays it:

<script>
async function update() {
  const data = await fetch('/api/status').then(r => r.json());

  document.querySelector('#plant1').textContent = data.moisture1;
  document.querySelector('#plant2').textContent = data.moisture2;
  document.querySelector('#plant3').textContent = data.moisture3;
}

setInterval(update, 5000);
update();
</script>

Add the BME280 and BH1750 values to the JSON and display them the same way.

7. Recommended build order

  1. ESP32 → Serial Monitor
  2. BME280 → temperature/humidity
  3. One soil sensor → raw readings
  4. Three soil sensors → calibrate each one
  5. One BH1750 → lux reading
  6. Wi-Fi → local web server
  7. Combine everything into /api/status
  8. Build the dashboard
  9. Deal with the second and third BH1750s if you still want three separate light readings

Stretch ideas

Possible additions once the core build works.

More equipment

TCA9548A I²C multiplexer
Gives each BH1750 its own channel, so all three light sensors work at once.
Small OLED screen
Shows readings at the pots without a browser. Usually an SSD1306 on the same I²C bus.
Water reservoir level sensor
A float switch or ultrasonic sensor that tells you when the tank needs topping up.
Soil temperature probe
A waterproof DS18B20 in one pot, to measure root-zone temperature, which can differ from air temperature.
CO₂ sensor
An SCD40 also reports temperature and humidity, so it could replace the BME280 if you want one fewer part.
Battery and deep sleep
Wake every few minutes, read, send, sleep. Lets you run it from a LiPo cell instead of a USB cable.
Pump and relay
This project has no pumps. If you add automatic watering, do it last, once the moisture readings are reliable.
Camera
An ESP32-CAM pointed at the plants to take a daily timelapse.

Further analysis

Keep a history
Log readings every few minutes to flash or an SD card and chart them. Everything below depends on this.
Drying rate per plant
Work out how fast each pot dries out, then estimate roughly when it will need water next.
Light totals
Add up lux over the day to compare how much light each position really gets, instead of reading single moments.
Vapour pressure deficit
Combine temperature and humidity from the BME280 into one number for how hard the plants are working to hold water.
Compare the pots
Line up moisture, light and growth for each plant to see which location suits basil best.
Alerts
Send a phone notification when a pot is too dry, using something like ntfy, or publish over MQTT to Home Assistant.

Useful rules

  • Power the sensors from 3.3 V unless their documentation says otherwise.
  • Keep the ESP32 and breadboard away from water.
  • Capacitive soil sensors are intended to stay in the soil; don't use exposed resistive probes for permanent monitoring.
  • Long sensor wires can pick up electrical noise. If a reading jumps around, average several readings in software.
  • The dashboard is local: the ESP32 and your phone/laptop need to be on the same Wi-Fi.
